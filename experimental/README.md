# experimental/

Side projects that are **not part of the BinML paper, its validation, or the released package**. Nothing here is
reviewed, versioned as a result, or used by `paper/`. Numbers in these notes are estimates or quick measurements
unless a file under `validation/` is cited.

- [`deployment/`](deployment/README.md) — how a BinML-style classifier could run on real Roman Galactic Bulge Time
  Domain Survey data: data access, alert streams, a cheap AWS plan, a CPU benchmark and an RMDC26 replay prototype.
